# Changelog

## zupmxode 0.0.0.9000

- Initial CRAN submission.

- [`pmx_ode_tier()`](https://pedrobtz.github.io/zupmxode/reference/pmx_ode_tier.md)
  reports and sets the tier a model runs on: native code generated by
  MIR, or MIR’s interpreter.

- [`pmx_ode_model()`](https://pedrobtz.github.io/zupmxode/reference/pmx_ode_model.md)
  compiles a model written in the subset of rxode2’s model language
  described in its documentation, including `linCmt()`.
